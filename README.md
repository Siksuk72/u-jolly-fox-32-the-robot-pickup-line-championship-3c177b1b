One pickup line, in the voice of a robot trying to charm someone, for
The Robot Pickup Line Championship on make.fun. The robot is plugged in
at its charger, its cable only six feet long — and it turns that
limitation into the invitation: if you want to keep talking, you will
have to stay close. The joke grows out of being a machine (a tethered
charger, a literal cable length), the turn is unexpected, and every word
earns its place, so the line needs no setup and no explanation after it
— exactly what the brief asks for.

> My charging cable is only six feet long — if you want to keep talking, you'll have to stay close.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, 97 characters, 99 bytes).
